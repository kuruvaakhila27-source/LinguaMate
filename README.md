# 🌍 LinguaMate

**AI-Powered Language Learning Assistant**

LinguaMate is an AI-powered language learning application designed to help learners improve their communication skills through conversation practice, pronunciation practice, vocabulary building, translation, and personalized feedback.

## ✨ Features

- 💬 **Conversation Practice** — Practice natural conversations with AI.
- 🎭 **Roleplay Mode** — Practice real-world situations like interviews, travel, restaurants, and college.
- 🧠 **Communication Analyzer** — Get feedback on grammar, vocabulary, fluency, and sentence formation.
- 📚 **Vocabulary Builder** — Save and manage useful words.
- 🎯 **Daily Challenges** — Complete daily speaking and communication challenges.
- 🌎 **Translation** — Translate sentences between multiple languages and learn from them.
- 🎤 **Voice Practice** — Convert speech to text and practice speaking.
- 🔊 **Pronunciation Practice** — Compare recognized speech with a target sentence.
- ⭐ **XP & Progress Tracking** — Earn XP and track your learning progress.
- 💾 **Conversation History** — Save and review previous conversations.

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/kuruvaakhila27-source/LinguaMate.git
cd LinguaMate
```

### 2. Create and activate a virtual environment

```bash
python -m venv venv
```

Windows:

```bash
venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install streamlit ollama SpeechRecognition pydub deep-translator streamlit-mic-recorder
```

### 4. Make sure Ollama is running

Install the required model:

```bash
ollama pull llama3.2:3b
```

### 5. Run the application

```bash
streamlit run app.py
```

The application will open in your browser.

## 📌 Project Purpose

LinguaMate aims to make language learning more interactive and practical by combining AI conversation, voice practice, translation, vocabulary learning, and progress tracking in one application.
